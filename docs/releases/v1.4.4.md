## What's new in 1.4.4

A maintenance release. **Nothing in the integration itself changes**: no
code, no entities, no services, and no change to the supported Home
Assistant floor. Updating is safe but optional. If you are on 1.4.3, you
are running the same integration code.

What changed is how it is tested and maintained.

### Tested against Home Assistant 2026.10.1

The latest test lane moves from Home Assistant 2026.9.0 to **2026.10.1**
(#61). The full suite and strict typing pass against it. The
minimum lane stays on **2025.8.0**, the floor declared in `hacs.json`.

### Tooling and CI

- Lint tooling: black 26.10.1, flake8 7.4.1, isort 9.0.2, mypy 2.4.0 and
  ruff 0.17.0, all clean against the codebase as it stands (#57).
- `actions/upload-artifact` 7.0.2 (#55) and a newer pinned hassfest
  action (#59). Both stay pinned to full commit SHAs.
- Dependabot no longer proposes pycares 5. It is pinned below 5 for the
  minimum lane only, because Home Assistant 2025.8.0's aiodns needs a
  symbol pycares 5 removed; every proposed bump broke that lane on import
  (#53, #60). The pin moves when the supported floor does.

Two Dependabot proposals were declined because they would have raised the
supported floor without anyone deciding to (#58, #60). Raising the floor
is a deliberate change made with `hacs.json` and the README, and this
release does not make it.

### Verification

Both lanes, the per-module coverage gate, strict typing, formatting,
hassfest, HACS and the protocol guards pass. Nothing new was verified on
hardware, since no integration behaviour changed.

### Install

HACS installs from the repository as usual and will offer 1.4.4 as the latest
release. For a manual install, download `unifi_play.zip` and unpack it into
`config/custom_components/`, then **restart** Home Assistant.

The archive is built from the tagged commit with fixed timestamps and file
modes, so rebuilding it from this tag reproduces the published checksum:

```
python scripts/build_release_archive.py
sha256sum -c dist/unifi_play.zip.sha256
```
